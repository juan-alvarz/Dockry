# Spec Delta

## MODIFIED Requirements

### Requirement: Catalog
Dockry SHALL have these widgets, listed in this order: Clock, Calendar, Spotify, Apple Music, Claude Usage, Weather, Switch User and Trash. Each SHALL be in a profile at most once.

#### Scenario: Widgets settings list
- **WHEN** the user opens Settings › Widgets
- **THEN** the eight widgets are listed in that order
